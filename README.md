# NEXUS-1.0
NEXUS 1.0 is a secure, local agentic AI platform built with Tauri 2.0, Rust + Candle, and React 18. Assign any task and 5 autonomous agents collaborate across 20+ GGUF models to produce superior results. All inference runs entirely on-device with AES-256 encryption and zero data exfiltration. Available for Windows, macOS, Linux, and Android.
